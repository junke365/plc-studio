# 用户指南

## 快速入门

### 安装

1. 确保已安装 Node.js >= 18 和 npm >= 9
2. 克隆仓库并安装依赖：

```bash
git clone https://github.com/junke365/plc-studio.git
cd plc-studio/smart-plc-studio
npm install
```

3. 启动开发服务器：

```bash
npm run dev
```

4. 打开浏览器访问 `http://localhost:5173`

### 创建新项目

1. 点击菜单栏 "文件" → "新建项目"
2. 输入项目名称和保存路径
3. 选择项目模板（空项目、PLC 控制、HMI 项目等）
4. 点击 "创建"

## 编程语言

### 梯形图 (LD)

梯形图是最常用的 PLC 编程语言，使用继电器逻辑符号。

**基本元素：**
- 常开触点 (NO)
- 常闭触点 (NC)
- 输出线圈 (Coil)
- 定时器 (Timer)
- 计数器 (Counter)

**示例：**
```
    X0          T0
----| |--------|/|----( Y0 )

    T0
----| |--------( Y1 )
```

### 功能块图 (FBD)

功能块图使用图形化的功能块连接。

**常用功能块：**
- AND、OR、NOT 逻辑运算
- 加法、减法、乘法、除法
- 比较运算
- 数据类型转换

### 结构化文本 (ST)

结构化文本是高级文本编程语言，语法类似 Pascal。

**示例：**
```pascal
PROGRAM Main
VAR
    counter : INT := 0;
    speed : REAL;
END_VAR

counter := counter + 1;

IF counter >= 100 THEN
    counter := 0;
    speed := 100.0;
END_IF;

// 调用功能块
MotorFB(
    Enable := TRUE,
    Speed := speed,
    ActualSpeed => speed
);
END_PROGRAM
```

## HMI 设计

### 基本操作

1. 在项目树中右键 → "新建 HMI 画面"
2. 从控件面板拖拽控件到画布
3. 在属性面板配置控件属性
4. 绑定 PLC 变量

### 支持的控件

- 按钮、开关、指示灯
- 数值显示、输入框
- 进度条、仪表盘
- 趋势图、历史曲线
- 文本、图片

### 数据绑定

在属性面板的 "数据绑定" 字段输入 PLC 变量名，实现动态显示和控制。

## CNC 运动控制

### 坐标系设置

1. 配置机器零点
2. 设置坐标系类型 (关节/笛卡尔/工具)
3. 配置轴参数 (行程、速度、加速度)

### G-code 编辑

支持标准 G-code 语法：

```
G00 X100 Y50        ; 快速定位
G01 X200 Y100 F500  ; 直线插补
G02 X150 Y80 R50    ; 顺时针圆弧
G03 X150 Y80 R50    ; 逆时针圆弧
M03 S1000           ; 主轴正转
M05                  ; 主轴停止
```

### 仿真

1. 点击工具栏 "仿真" 按钮
2. 在 3D 视图中观察运动
3. 使用暂停/步进控制
4. 查看变量实时值

## 调试功能

### 变量监控

- 实时显示变量值
- 支持数值、布尔、字符串类型
- 历史数据记录

### 断点调试

- 在 ST 代码中设置断点
- 单步执行
- 查看调用栈

### 在线修改

- 运行时修改变量值
- 强制变量输出
- 下载修改到运行时

## 项目管理

### 文件结构

```
my-project/
├── project.json        # 项目配置
├── plc/               # PLC 程序
│   ├── main.prg       # 主程序
│   ├── fb_motor.fbd   # 功能块
│   └── var.csv        # 变量表
├── hmi/               # HMI 画面
│   └── main.hmi
└── export/            # 编译输出
```

### 导出

- **编译** - 生成运行时代码
- **下载** - 连接目标设备
- **导出** - 生成可执行文件
