# 架构设计

## 系统架构概览

PLC Studio 采用分层架构设计，将编辑器、服务端和运行时分离，支持灵活的部署和扩展。

│  │  │   LD    │ │   FBD   │ │   ST    │ │   HMI   │  │   │
│  │  └─────────┘ └─────────┘ └─────────┘ └─────────┘  │   │

                              │

## 模块详解

### 1. Editor (前端编辑器)

基于 Vue 3 + TypeScript 构建的 Web 编辑器，负责用户界面和交互。

**技术选型：**
- **Vue 3** - 组合式 API，更好的 TypeScript 支持
- **Pinia** - 状态管理
- **Naive UI** - UI 组件库
- **Monaco Editor** - 代码编辑器 (ST 语言)
- **Fabric.js** - 2D 图形编辑 (LD/FBD)
- **Three.js** - 3D 运动仿真

**核心组件：**
```
editor/src/
├── components/
│   ├── editors/           # 编辑器组件
│   │   ├── LD/           # 梯形图编辑器
│   │   ├── FBD/          # 功能块图编辑器
│   │   ├── ST/           # 结构化文本编辑器
│   │   ├── HMI/          # HMI 设计器
│   │   └── Kinematics/   # 运动学仿真
│   ├── debug/            # 调试面板
│   ├── library/          # 功能块库
│   ├── project/          # 项目树
│   └── simulator/        # 仿真面板
├── layouts/              # 布局组件
├── stores/               # Pinia 状态
└── views/                # 页面视图
```

### 2. Server (后端服务)

基于 Fastify 构建的 RESTful API 和 WebSocket 服务。

**功能模块：**
- **Project Service** - 项目文件管理
- **Runtime Service** - 运行时通信
- **Debug Gateway** - 实时调试数据
- **HMI Service** - HMI 资源管理

**通信协议：**
- HTTP/REST - 静态资源和 CRUD 操作
- WebSocket - 实时调试数据推送
- Socket.IO - 双向通信

### 3. Runtime (C 运行时)

高性能 C 语言运行时，支持多种嵌入式平台。

**模块划分：**
- **Core** - PLC 扫描周期、任务调度、变量管理
- **HAL** - 硬件抽象层 (GPIO、ADC、SPI、I2C、CAN、UART)
- **HMI** - HMI 渲染引擎 (LVGL、SDL2、Linux FB、Windows)
- **Protocol** - 工业通信协议 (Modbus、EtherCAT、CANopen)

**平台支持：**
| 平台 | 特性 | 适用场景 |
|------|------|---------|
| ESP32 | WiFi/BLE、低功耗 | IoT、小型设备 |
| STM32 | 丰富外设、实时性 | 工业控制 |
| Linux | 完整 POSIX、多线程 | 工控机、边缘计算 |
| Xenomai | 实时补丁、硬实时 | 高性能运动控制 |

### 4. Shared (共享类型)

TypeScript 类型定义，确保前后端类型一致。

## 数据流

```
用户操作 → Editor → Server API → Runtime → 硬件设备
                ↑                ↓
                └── WebSocket ←──┘
```

1. **编辑阶段**：用户在 Editor 中编写程序，通过 Server 保存到项目文件
2. **编译阶段**：PLC 代码转换为运行时可执行格式
3. **运行阶段**：Runtime 加载程序，按扫描周期执行
4. **调试阶段**：通过 WebSocket 实时获取运行状态

## 通信协议

### Modbus

支持 Modbus RTU (串口) 和 Modbus TCP (网络)。

### EtherCAT

高性能工业以太网协议，支持分布式时钟。

### CANopen

基于 CAN 总线的高层协议，支持运动控制 profiles。

## 安全设计

- 前后端分离，API 鉴权
- 运行时内存隔离
- 看门狗定时器
- 故障安全机制
